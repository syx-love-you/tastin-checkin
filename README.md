# 塔斯汀每日自动签到

Android App 每日自动签到 + Windows 电脑端 token 提取工具。当前版本为 **v1.0**。

token 只用于访问塔斯汀官方接口 `sss-web.tastientech.com`，数据全部保存在用户自己的设备上。

## 功能

- 每日定时签到，时间精确到分钟
- 打开应用时自动检查当天签到状态
- 失败自动重试，最多 3 次
- 扫码导入 token，支持凭证失效提醒
- 签到日志保留 30 天
- 应用内检查更新

## 使用流程

1. 在 Windows 电脑上打开微信，进入塔斯汀小程序
2. 双击 `提取Token.exe` 生成二维码
3. 在 Android 7.0+ 手机上安装应用，扫码导入 token
4. 按引导允许通知、精确闹钟、后台运行和自启动
5. 选择每天的签到时间并保存

详细使用说明见 [docs/手机端使用说明.md](docs/手机端使用说明.md) 和 [docs/电脑抓取工具使用说明.md](docs/电脑抓取工具使用说明.md)。

## 隐私与安全

- token 只保存在本机，不上传到任何第三方服务器
- 签到请求只访问塔斯汀官方接口
- `config.json` 和 `二维码.html` 是本地运行产物，包含账号凭证，使用后应删除
- 本仓库只包含源代码和文档，不包含真实 token、签名密钥、本机配置、APK 或 EXE
