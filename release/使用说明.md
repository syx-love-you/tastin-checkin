# 塔斯汀签到 App 使用说明

**安装包**：`塔斯汀签到.apk`（2.5 MB，支持 Android 7.0 及以上）

---

## 这个 App 是干什么的

每天自动帮你在塔斯汀小程序签到，不用你自己点。

**它需要你自己提供 token**。原因很简单：token 就是你的账号凭证，只有你本人能拿到，
别人的 token 对你没用，我也没法替你获取。

---

## 一、先拿 token（需要一台 Windows 电脑）

手机上的微信有证书绑定校验，不 root 手机读不到它的流量，所以这一步只能在电脑上做。

1. 电脑上打开微信 → 搜索「塔斯汀」→ 进入小程序，等页面加载完
2. **保持小程序开着**，双击 `提取Token.exe`
3. 约 2 秒出结果，电脑屏幕上会自动弹出一个二维码页面
4. 手机 App 点「扫码获取（推荐）」，对准电脑屏幕扫码

> 不需要安装任何东西：不用 Python、不用 Node.js。
> 如果杀毒软件拦截，把 exe 加入信任列表即可——它只读微信进程内存，不联网、不修改任何东西。
>
> **没有 Windows 电脑？** 借一台用几分钟即可，抓一次 token 能用很久。
> 本工具只支持 Windows。

---

## 二、手机上安装并配置

1. 安装 `塔斯汀签到.apk`
2. 首次打开会问通知权限，**选允许**（否则签到了不提醒你）
3. 扫码后 App 会自动验证 token，提示「token 有效，当前 XX 积分」就成功了
4. 按引导完成精确闹钟、后台无限制和自启动设置（见下一节）
5. 点时间那一栏，选每天几点几分签到
6. 点「保存并启用定时签到」

---

## 三、必做：允许精确闹钟和后台运行

App 会在首次配置时逐项引导。点击状态栏里的「后台保障」也可以重新检查。

1. 允许「闹钟和提醒」权限，保证到点准时唤醒
2. 允许「后台运行」或把省电策略设为「无限制」
3. 在系统支持时允许「自启动」，保证重启后恢复定时

国产 ROM 的具体入口：

**小米 / Redmi（MIUI、HyperOS）**
设置 → 应用设置 → 应用管理 → 塔斯汀签到 → **省电策略 → 无限制**

**OPPO / 一加 / realme（ColorOS）**
设置 → 电池 → 应用耗电管理 → 塔斯汀签到 → **允许后台活动**

**华为 / 荣耀（EMUI、HarmonyOS）**
设置 → 电池 → 启动管理 → 塔斯汀签到 → 关闭自动管理，三个开关全开

**vivo（OriginOS）**
设置 → 电池 → 后台耗电管理 → 塔斯汀签到 → **允许后台高耗电**

另外建议在「自启动管理」里允许本应用，这样手机重启后定时任务能自动恢复。

---

## 它会不会很耗电

不会。它在后台**不运行**，只在设定的那一刻被系统叫醒一次，几秒钟签完就结束。

- 没有常驻后台的进程
- 没有一直开着的服务
- 平时完全不活动

每天的联网开销不到 2 秒，电量消耗可以忽略。

---

## 签到失败了怎么办

App 会自动重试，你不用管：

- 失败后隔 **1 小时**再试一次
- 每天最多试 **3 次**
- App 内「状态」右侧的「日志 ›」可以看最近 30 天每次成功和失败的具体原因

常见原因：

| 提示 | 什么意思 | 怎么办 |
|---|---|---|
| token 已失效（弹窗） | 凭证过期了 | 按第一节重新抓一次，扫码导入 |
| 网络不通 | 手机没联网 | 检查网络，它会自己重试 |
| 未找到进行中的签到活动 | 活动还没开始或已结束 | 等官方活动上线 |

**token 失效会弹窗提醒你**，因为不处理的话之后每天都会失败。
其他失败只会重试，不会打扰你。

## 关于隐私

- token **只存在你自己的手机里**，不会上传到任何服务器
- 这个 App 只会连接 `sss-web.tastientech.com`（塔斯汀官方接口），不连接其他任何地方
- 电脑上生成的 `config.json` 和 `二维码.html` 里就是你的 token，**不要截图发给别人**，用完可删
- 卸载 App，数据就全部清除

## 常见问题

**Q：能给别人用吗？**
A：可以把 APK 发给别人，但**每个人必须自己抓自己的 token**。
不能用同一个 token 给多人用——那等于共用一个账号，很快会被风控。

**Q：要天天抓 token 吗？**
A：不用。token 有效期比较长，只有 App 通知你「token 已失效」时才需要重抓。

**Q：为什么手机上不能直接抓？**
A：微信的流量是加密的（HTTPS + 证书绑定校验），普通 App 读不到内容。
要读就必须 root 手机装系统证书，风险大且微信会检测。所以只能在电脑上抓一次。

**Q：签到记录在哪看？**
A：打开 App，点「状态」右边的「日志 ›」，能看到最近 30 天的记录和失败原因。

**Q：从最近任务里划掉了 App，定时还有效吗？**
A：通常仍有效。应用有 15 分钟一次的后台心跳兜底：如果定时点已过但当天签到还没完成，
系统会拉起应用补签一次。下次打开 App 时也会自动检查并补签。
不过部分手机系统仍可能清理后台任务，所以建议保留自启动和后台无限制设置。

## 关于更新

App 会自动检查新版本。发现更新时会弹窗，点「立即更新」就会自动下载安装，
不需要你去别处找安装包。

也可以手动检查：拉到页面最底下，点「版本 X.X · 点此检查更新」。

第一次更新时，系统会问你是否允许本应用安装应用，选**允许**即可
（只会问这一次）。

---

## 卸载方法

长按图标 → 卸载。所有数据随之清除，无需额外操作。
