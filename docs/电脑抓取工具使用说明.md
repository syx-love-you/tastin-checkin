# 电脑端工具（获取 token 用）

**双击 `提取Token.exe` 就能用，什么都不用安装。**

不需要 Python、不需要 Node.js、不需要 frida，也不用联网下载任何东西。

> **请先解压再运行。** 不要在压缩包里直接双击——程序需要在所在目录生成二维码文件，
> 直接从 zip 里运行会失败或找不到输出。

---

## 使用方法

### 1. 微信里打开塔斯汀小程序

打开微信 → 搜索「塔斯汀」→ 进入小程序，等页面加载完。

**保持打开状态**（前台后台都行，但别关掉）。

### 2. 双击 `提取Token.exe`

如果小程序还没开，程序会等你打开（最多 2 分钟），开了就自动继续：

```
[1/3] 检测小程序...

      检测到 12 个小程序进程
      等它加载完整…

[2/3] 读取内存（第 1 次）...

[3/3] 找到 1 个 token

TOKEN=<YOUR_TOKEN>

已保存到 config.json
  已生成二维码页面，正在打开...
```

浏览器会自动弹出一个二维码页面。手机 App 点「扫码获取」，对准屏幕扫即可。

### 3. 关闭浏览器页面，按回车退出

## 遇到问题

| 提示 | 原因 | 解决 |
|---|---|---|
| 等了 2 分钟没检测到小程序 | 小程序没打开 | 微信里进一次塔斯汀小程序 |
| 没读到 token | 小程序刚开还没加载完 | 程序会自动重试 3 次；也可以在小程序里点进签到页再等它重试 |
| 程序没有权限读取微信的内存 | 被系统或安全软件拦了 | **右键 exe → 以管理员身份运行** |
| 浏览器没自动打开 | 默认浏览器配置问题 | 双击同目录的 `二维码.html` |

**杀毒软件报警？** 这个程序会读取其他进程的内存，某些安全软件会敏感。
如果被拦，把它加入信任列表。它只读取微信小程序进程，不修改任何东西、不联网。

---

## 原理

微信登录后会把 token 明文保存在小程序进程（`WeChatAppEx.exe`）的内存里。

这个程序用 Windows 系统接口把那块内存读出来，按格式匹配 token。
**不注入代码、不修改微信、不联网。**

---

## 安全提醒

- `config.json` 和 `二维码.html` 里**就是你的 token**，等于账号钥匙
- 用完请删掉这两个文件
- **不要截图二维码发给任何人**
- 程序除了读内存，不连接任何地方
